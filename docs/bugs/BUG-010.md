# BUG-010: Modified JWT returns 500 instead of 401 on GET /auth/me

**Application:** DummyJSON API - [Auth](https://dummyjson.com/docs/auth)
**Endpoint:** `GET https://dummyjson.com/auth/me`
**User:** `emilys`
**Severity:** Medium
**Priority:** Medium

**Steps to reproduce:**
1. Log in with `POST /auth/login` with valid credentials `emilys` / `emilyspass`
2. `accessToken` from the response
3. Decode the JWT payload and change username to emilys1, keeping the original header and signature.
4. Send `GET /auth/me` with the header `Authorization: Bearer <modified token>`

**Actual result:** the server responds with **500 Internal Server Error**. No user data is returned, so access is correctly denied.

**Expected result:** the server responds with **401 Unauthorized**, because the token signature does not match its content.

**Observation:** the security check works (the modified token does not give access to any account), but the status code is wrong. 

**Test:** `tests/apiDummyJSON/scenario7.spec.ts` - `modified JWT is rejected` (tagged `@known-bug`)

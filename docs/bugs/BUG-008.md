# BUG-008: Upload accepts unsupported file types

**Application:** UI Testing Playground - [Upload](http://uitestingplayground.com/upload)
**Severity:** Medium
**Priority:** Medium

**Steps to reproduce:**
1. Open the Upload page
2. Select or drag and drop a file with an unsupported type (for example `program.exe` or `image.png`)

**Actual result:** the file is added to the list and the message **1 file(s) selected** is displayed.

**Expected result:** the file is rejected, because the page states: *Supported files: .PDF, .DOCX, .PPTX, .TXT, .XLSX*. The user is informed that the type is not supported.

**Observation:** The type must be validated by the application.

**Test:** `tests/uiPlayground/upload.spec.ts` - `unsupported type is rejected - program.exe`, `unsupported type is rejected - image.png` (tagged `@known-bug`)

# BUG-005: Sorting by price has no effect with error_user
 
**User:** `error_user`
**Severity:** Medium
**Priority:** Medium
 
**Steps to reproduce:**
1. Log in with `error_user` / `secret_sauce`
2. On the inventory page, select **Price (low to high)** from the sort dropdown
**Actual result:** the selection is ignored. The dropdown stays on **Name (A to Z)** and the products are not reordered.
 
**Expected result:** the dropdown shows **Price (low to high)** and the products are sorted by price in ascending order. The same applies to **Price (high to low)**.
 
**Observation:** the user cannot sort products by price. The products can still be found and bought, so the main flow is not blocked.

**Test:** `tests/sauceDemo/scenario2.spec.ts` - `sort products by price` (user: `error_user`, tagged `@known-bug`)

# BUG-009: Upload does not enforce the 15MB file size limit

**Application:** UI Testing Playground - [Upload](http://uitestingplayground.com/upload)
**Severity:** Medium
**Priority:** Medium

**Steps to reproduce:**
1. Open the Upload page
2. Select or drag and drop a supported file larger than 15MB (15 728 641 bytes, one byte over the limit)

**Actual result:** the file is added to the list and the message **1 file(s) selected** is displayed.

**Expected result:** the file is rejected, because the page states: *Limit 15MB per file*. The user is informed that the file is too large.

**Observation:** file of exactly 15MB is accepted (correct), but a file one byte over the limit is accepted too. The specification does not say whether 15MB means 15 000 000 or 15 728 640 bytes; the tests use 15 × 1024 × 1024 bytes. This should be clarified with the product owner.

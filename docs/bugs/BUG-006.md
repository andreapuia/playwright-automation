# BUG-006: Checkout can be started with an empty cart
 
**User:** all users (tested with `standard_user`)
**Severity:** Medium
**Priority:** Medium
 
**Steps to reproduce:**
1. Log in with `standard_user` / `secret_sauce`
2. Without adding any product, open the cart
3. Click **Checkout**

**Actual result:** the user is taken to the **Checkout: Your Information** page and can continue the checkout flow with no products in the cart.
 
**Expected result:** checkout is not possible with an empty cart (for example, the **Checkout** button is disabled or a message asks the user to add products first).
 
**Observation:** lower limit of the cart: 0 products

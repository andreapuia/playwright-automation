# BUG-007: Cart is shared between users after logout
 
**User:** all users (tested with `standard_user` and `problem_user`)
**Severity:** High
**Priority:** High
 
**Steps to reproduce:**
1. Log in with `standard_user` / `secret_sauce`
2. Add a product to the cart
3. Open the menu and click **Logout**
4. Log in with `problem_user` / `secret_sauce` in the same browser

**Actual result:** the cart badge shows **1**: the new user sees the product added by the previous user.
 
**Expected result:** each user starts with their own cart. After logout, the previous user's cart is not visible to the next user.
 
**Observation:** logout ends the session but does not clear the cart, which is kept in the browser's local storage

**Test:** `tests/sauceDemo/cart.spec.ts` - `cart is not shared between users after logout` (tagged `@known-bug`)

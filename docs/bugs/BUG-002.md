# BUG-002: Add to cart fails without an error message
 
**User:** `error_user`
**Severity:** High
**Priority:** High
 
**Steps to reproduce:**
1. Log in with `error_user` / `secret_sauce`
2. Click **Add to cart** on the three most expensive products
3. Open the cart

**Actual result:** only one product (Sauce Labs Backpack) is in the cart. No error message is displayed for the products that were not added.
 
**Expected result:** all three products are in the cart or, if adding fails, the user is informed through an error message.
 
**Observation:** the user does not know the action failed and may place an incomplete order.

**Test:** `tests/sauceDemo/scenario1.spec.ts` - `place an order with 3 most expensive products` (user: `error_user`, tagged `@known-bug`)
